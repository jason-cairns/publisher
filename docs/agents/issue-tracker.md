# Issue tracker: GitHub

Issues and PRDs for this repo live in GitHub Issues for `jason-cairns/my-site`.

Use the inbuilt GitHub connector for issue and PRD work. Do not use the `gh` CLI for normal issue-tracker operations in this repo.

## Conventions

- Create issues with the GitHub connector.
- Read issues, comments, labels, and status with the GitHub connector.
- Add comments with the GitHub connector.
- Apply or remove labels with the GitHub connector.
- Close issues with the GitHub connector.

Infer the repo from `git remote -v` when needed. The current remote is `git@github.com:jason-cairns/my-site.git`.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `jason-cairns/my-site` using the GitHub connector.

## When a skill says "fetch the relevant ticket"

Read the GitHub issue and its comments using the GitHub connector.
